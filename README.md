# Albumlet

Downloads of Albumlet for Mac. Albumlet needs macOS 15 or later.

## Installing

Download the zip from the [latest release](https://github.com/peterloveland/Albumlet-releases/releases/latest), open it, and drag Albumlet into Applications.

After that, choose **Albumlet › Check for Updates…** to install a newer version. Albumlet also checks once a day by itself.
